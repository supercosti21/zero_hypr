# =============================================================================
#  Pacchetti dell'ambiente.
#
#  TUTTI dai repo ufficiali: niente AUR, mai. CachyOS impila i propri repo
#  SOPRA core/extra/multilib di Arch, che restano attivi, quindi `pacman -S`
#  risolve sull'unione dei due — non serve abilitare niente.
#
#  Formato: un pacchetto per riga. Righe vuote e righe con # ignorate.
#  Lo legge sistema/pacchetti.sh, che prima di installare controlla ogni nome
#  con `pacman -Si` e dice quali mancano, invece di far abortire l'intera
#  transazione per un nome sbagliato.
#
#  Questa e' la fonte di verita' unica: il README rimanda qui e non duplica
#  l'elenco.
# =============================================================================
